# Bot by maroneya (Paper 26.2) — beta-26.2

ปลั๊กอินเสกกองทัพผู้เล่นปลอม (ชื่อ/สกินสุ่ม ไม่ใช่ซอมบี้) ลาดตระเวนเป็นแถว โจมตี และถอยไปกินแอปเปิลทอง

**ต้องมี:** Paper 26.2 , Java 25 , [Citizens](https://ci.citizensnpcs.co/) (ปลั๊กอินนี้ใช้ Citizens เป็นตัวสร้างผู้เล่นปลอม)

## คำสั่ง
| คำสั่ง | ทำอะไร |
|---|---|
| `/bot` | เปิดเมนูเลือกชุดบอท (กล่องใหญ่ กดเขียว = เสก / แดง = ยกเลิก) |
| `/bot macex` | เสกบอท MACE PVP **ฝีมือระดับโลก 1 ตัว** (ไม่พลาด เร็วสุด คอมโบเด้งทุบ 5 ครั้ง โทเทม 8) |
| `/bot frozen` | แช่/ปลดแช่บอท ทุกตัวถือโทเทมสแตก 99 |
| `/bot mode <auto\|patrol\|attack>` | บังคับโหมดกองทัพ |
| `/bot kill <ชื่อผู้เล่น>` | สั่งบอทรุมผู้เล่นคนนั้น ถ้ามีบอทเกิน 2 ตัว **แบ่งครึ่ง**ไปรุม ที่เหลือทำงานตามปกติ (≤2 ตัวไปรุมหมด) |
| `/bot kill clear` | ยกเลิกคำสั่งรุม (เลิกเองเมื่อเป้าตาย) |
| `/debot` | ล้างบอททุกตัว |

สิทธิ์: `botarmy.admin` (op) / `botarmy.ignore` (บอทไม่โจมตีคนนี้)

## เมนูเลือกชุดบอท
กล่องใหญ่ 6 แถว มีกระจกล้อม กดได้เฉพาะปุ่มตั้งค่า (ทุกคลิกในเมนูถูกยกเลิก ไม่มีของหลุดออกมา)
- **ชุด (kit)** เลือก 1: `CPVP` · `CUTPVP` · `SMP` · `FFA` · `UHC` · `AXE PVP` · `MACE PVP`
- **ระดับบอท** เลือก 1: ต่ำ / กลาง / ยาก (กระทบ AI: ความแม่น ความเร็ว โล่ โดดตี ท่าไม้ตาย)
- **ถือโทเทม** เลือก 1: ถือ / ไม่ถือ
- **โทเทมสแตก 99** เลือก 1: ถือ / ไม่ถือ (เลือกถือสแตก 99 = ถือโทเทมอัตโนมัติ, เลือกไม่ถือโทเทม = ไม่มีสแตก 99)
- **จำนวน** เลือก 1: 1 / 5 / 10 / 15 / 20 / 30 / 50
- **❄ Frozen** (ปุ่มน้ำแข็งแถวที่ 3 ขวาสุด): กดสลับ แช่/ปลดแช่ บอททั้งหมดทันที (เหมือน `/bot frozen`) ปุ่มจะเรืองแสงเมื่อกำลังแช่อยู่
- ล่างสุดตรงกลาง: 🟢 เขียว = เสกบอท · 🔴 แดง = ยกเลิก (ปิดเมนูเฉยๆ ก็คือยกเลิก)

## ระดับบอท
- **ต่ำ**: ตีพลาดบ่อย ไม่โดดตี โล่ไม่ฉลาด ไม่กินแอปเปิล/ไม่ใช้เพิร์ล (CPVP/CUTPVP ยังใช้คริสตัล/รถระเบิดได้ แต่ช้าและมั่ว)
- **กลาง**: **โดดตีคริติคอล** (~65% ของการตี โดดให้ตกลงมาตีตอนคูลดาวน์ครบพอดี) ตีแม่น เดินเร็วปานกลาง ใช้โล่/แอปเปิล/เพิร์ลบางส่วน — ไม่โหดเกินไป
- **ยาก**: โดดตีแทบทุกครั้ง (~97%) + W-tap (แรงสะบัดเพิ่ม) ตีแทบไม่พลาด เร็ว โล่ฉลาด ท่าไม้ตายครบ

## ชุดบอท
- **CPVP**: เนเธอร์ไรต์ Prot 4 + ดาบ Sharp 5, แอปเปิลทองเอนฯ, เพิร์ล
  **วางคริสตัล:** บอทสแกนจุดรอบศัตรู (ออบซิเดียน/เบดร็อกที่มีอยู่ หรือวางออบซิเดียนชั่วคราวก่อน) คำนวณดาเมจด้วยสูตรระเบิดจริง (power 6 + สิ่งกำบัง)
  ให้คะแนน = ดาเมจศัตรู − ความกลัวดาเมจตัวเอง แล้ววางคริสตัลระเบิดทันที — เลือดตัวเองไม่พอจะไม่วาง, ยืนห่างในระยะวาง
  | ระดับ | หน่วงก่อนระเบิด | วางทุก | เลือกจุด |
  |---|---|---|---|
  | ต่ำ | 8 tick | ~3.5 วิ | สุ่ม ไม่กลัวเจ็บตัว |
  | กลาง | 4 tick | ~1.1 วิ | ดี ยอมเจ็บตัวไม่เกิน 60% เลือด |
  | ยาก | 1 tick | 0.3 วิ | ดีที่สุด ระวังตัว + รีวางทันทีเมื่อศัตรูแตกโทเทม |
  บล็อกไม่พัง (ปรับที่ `crystal-block-damage`), ออบซิเดียนที่วางหายเอง
- **CUTPVP** (Cart PvP): เนเธอร์ไรต์ Prot 3, ดาบ + ขวาน (ขวานตัดโล่แล้วตีต่อ)
  **รถรางระเบิด:** วางรางชั่วคราว + TNT Minecart รอบเท้าศัตรู แล้วจุดด้วยไฟแช็ก (ฟิวส์ ต่ำ 3 วิ / กลาง 1.8 วิ แล้วถอยหนีรัศมีระเบิด)
  ระดับ **ยาก** วาง 3 คัน แล้ว **ยิงธนูไฟจุดทันที** (ศัตรูไม่มีเวลาหนี) กลาง 2 คัน ต่ำ 1 คัน
  **ธนู/หน้าไม้ไฟ:** ยิงระยะไกลเล็งนำเป้า + ชดเชยแรงโน้มถ่วง (ความแม่นตามระดับ) บอทแต่ละตัวสุ่มถือธนูหรือหน้าไม้
  รถระเบิดไม่ทำร้ายบอทด้วยกันเอง, ไม่พังบล็อก (ปรับที่ `cart-block-damage`)
- **SMP**: เพชร Prot 3, ดาบเพชร, โล่, แอปเปิลทอง
- **FFA**: เนเธอร์ไรต์ Prot 4, ดาบ+ขวาน+ค้อน Mace + Wind Charge (ระดับยากมี Elytra คอมโบ)
- **UHC**: เพชร Prot 2, ดาบเพชร, ใยแมงมุม + ลาวา/น้ำ ใส่ศัตรู
- **AXE PVP** (ใหม่): เนเธอร์ไรต์ Prot 4 + **ขวานเนเธอร์ไรต์ Sharp 5 อย่างเดียว** (ไม่มีดาบ), โล่, แอปเปิลทองเอนฯ, เพิร์ล
  ตีช้าแต่หนัก (คูลดาวน์ 1 วิ) เน้นโดดตีคริติคอลให้ตรงจังหวะ และทำลายโล่ศัตรูทุกครั้งที่ตีโดนคนยกโล่
- **MACE PVP** (ใหม่): เนเธอร์ไรต์ Prot 4 (Feather Falling 4) + **ค้อน Mace อย่างเดียว** (Density 5 / Breach 4 / Wind Burst 3) + ขวานไว้ตัดโล่ + Wind Charge
  | ระดับ | ท่าทุบจากฟ้า | คอมโบเด้งซ้ำ | พิเศษ |
  |---|---|---|---|
  | ต่ำ | ไม่ใช้ Wind Charge (ตีค้อนธรรมดา) | – | – |
  | กลาง | ลอยตัวทุบ ~55% ของจังหวะ | 1 ครั้ง | – |
  | ยาก | ลอยตัวทุบเกือบทุกจังหวะ คูลดาวน์สั้น | 3 ครั้ง (Wind Burst เด้งทุบต่อ) | Elytra บินเข้าหาระยะไกลแล้วทุบ |
  **เทคนิคค้อน (ระดับกลาง/ยาก/macex):**
  1. **ลอยตัวทุบ** – Wind Charge ดีดตัวขึ้นแล้วทิ้งตัวทุบ Density + Wind Burst เด้งต่อเป็นสายพาน
  2. **ขวานทุบโล่ → ต่อค้อน** – ศัตรูยกโล่ บอทสลับขวานทุบโล่แตก แล้วลอยตัวทุบค้อนทันทีตอนโล่ยังใช้ไม่ได้
  3. **เพิร์ล + Wind Charge** – ปาเพิร์ลวาร์ปไปถึงตัวศัตรู แล้วดีดตัวด้วย Wind Charge ทิ้งตัวทุบ
  4. **ปีกบินสลับเกราะทุบ (ยาก/macex)** – สลับเกราะเป็นปีก บินขึ้นสูง สลับกลับเป็นเกราะกลางอากาศ ทุบ แล้วสลับปีกบินขึ้นทุบวนซ้ำ (3 รอบ ยาก / 5 รอบ macex)
  5. **ศัตรูยืนในหลุม** – ถ้าศัตรูอยู่ต่ำกว่า บอทจะบินทุบจากข้างบนทันที (ไม่รอสุ่ม) และถ้าลงพื้นแล้วยังไม่โดนจะบินใหม่ได้อีก 3 ครั้ง
  ฉลาด: ไม่เริ่มท่าถ้าศัตรูยกโล่ (สลับขวานตัดโล่ก่อนแล้วค่อยทุบ), ไม่ลอยถ้าเลือดตัวเองต่ำ, ถ้าศัตรูใกล้ตายใช้ตีธรรมดาจบเร็วกว่า,
  คำนวณระยะ/ทิศพุ่งใส่เป้า, ตกพื้นรีเซ็ตระยะตก, โล่ยกกันค้อนของศัตรูที่โดดลงมา

> ของสิ้นเปลืองประจำชุด (คริสตัล/ออบซิเดียน/รถระเบิด/ราง/ไฟแช็ก/ลูกธนู) จะไม่ดรอปตอนบอทตาย

ใยแมงมุม/ลาวา/น้ำ/ราง/ออบซิเดียนที่บอทวางเป็นบล็อกชั่วคราว **คืนค่าเดิมเอง** (ตั้งเวลาใน config / ปิดทั้งหมดที่ `traps-enabled: false`)

## ความฉลาดของบอท
- เลือกเป้าแบบให้คะแนน: ใกล้ + เลือดน้อย + ไม่สลับเป้าไปมา, ป้องกันตัวจากคนที่เพิ่งตี, โดนตีตัวเดียวทั้งทัพหันมาช่วย
- ล้อมเป็นวงรอบเป้า (แต่ละตัวคนละมุม) ไม่เดินแถวเดียว, สลับทิศหลบเมื่อโดนตี
- ตั้งโล่ใส่ธนู/หน้าไม้/ตรีศูล, ไม่ตั้งโล่เมื่อเป้าเลือดใกล้หมด (รีบจบเกม)
- ติดกำแพง/หลุม → กระโดด → ปาเพิร์ล → วาร์ปไปหาเป้า
- ตัดใยแมงมุมที่ติดเอง, ขึ้นจากลาวา, เทน้ำดับไฟตัวเอง
- ตายแล้วดรอปของ (`drop-items: true` ใน config)

## Build
- GitHub: push แล้วดูไฟล์ใน Actions → Artifacts → `BotByMaroneya.jar`
- เครื่องตัวเอง: `mvn package` → `target/BotByMaroneya.jar`
- ถ้า build ไม่ผ่านเพราะหา Citizens ไม่เจอ ให้แก้เลขเวอร์ชัน `citizens-main` ใน `pom.xml`

ค่าปรับแต่งทั้งหมดอยู่ใน `config.yml`

## แจ้งเตือนเข้า/ออกเกม
ตอนเสกบอทจะขึ้น `ชื่อบอท joined the game` และตอน `/debot` จะขึ้น `left the game` ทยอยทีละตัว
ปิดได้ที่ `broadcast-join-leave: false` ใน `config.yml`
