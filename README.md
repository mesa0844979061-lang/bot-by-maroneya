# Bot by maroneya (Paper 26.2)

ปลั๊กอินเสกกองทัพผู้เล่นปลอม (ชื่อ/สกินสุ่ม ไม่ใช่ซอมบี้) ลาดตระเวนเป็นแถว โจมตี และถอยไปกินแอปเปิลทอง

**ต้องมี:** Paper 26.2 , Java 25 , [Citizens](https://ci.citizensnpcs.co/) (ปลั๊กอินนี้ใช้ Citizens เป็นตัวสร้างผู้เล่นปลอม)

## คำสั่ง
| คำสั่ง | ทำอะไร |
|---|---|
| `/bot <easy\|medium\|high\|max> [จำนวน]` | เสกกองทัพ (ไทยก็ได้: ง่าย/กลาง/สูง/สูงสุด) |
| `/bot frozen` | แช่/ปลดแช่บอท ทุกตัวถือโทเทมสแตก 99 |
| `/bot mode <auto\|patrol\|attack>` | บังคับโหมดกองทัพ |
| `/bot kill <ชื่อผู้เล่น>` | สั่งบอทรุมผู้เล่นคนนั้น ถ้ามีบอทเกิน 2 ตัว **แบ่งครึ่ง**ไปรุม ที่เหลือทำงานตามปกติ (≤2 ตัวไปรุมหมด) |
| `/bot kill clear` | ยกเลิกคำสั่งรุม (เลิกเองเมื่อเป้าตาย) |
| `/debot` | ล้างบอททุกตัว |

สิทธิ์: `botarmy.admin` (op) / `botarmy.ignore` (บอทไม่โจมตีคนนี้)

## ระดับ
- **easy**: เกียร์เหล็ก ดาบ+โล่ · **ใยแมงมุม** ขังเท้า/หัวเป้า · **ลาวา+น้ำ** (เทลาวาที่เท้า แล้วเทน้ำดับเป็นออบซิเดียน)
- **medium**: เกียร์เพชร, เอนเดอร์เพิร์ล, แอปเปิลทอง (ถอยไปกิน), โทเทมบางตัว · ใยแมงมุมล้อม 3 ด้าน + ลาวา+น้ำถี่ขึ้น
- **high** (เนิฟ): เกราะ**เพชร** prot 3 (เดิมเนเธอไรต์), แอปเปิล 6, โทเทม 2 · ค้อน mace + วินชาร์จ, ขวานหักโล่, กระโดดคริ
- **max** (เนิฟเกราะ + บัพท่า): เนเธอไรต์ prot 2 (เดิม 4, ตัด Thorns), แอปเปิลทองเอนฯ 8 (ผลสั้นลง), โทเทม 4 ·
  **ท่าแบบ Wemmbu**: ใส่ปีก elytra (สลับเกราะ→ปีก) บินไล่ด้วยแรงเร่งแบบพลุ → สลับกลับเกราะกลางอากาศ → ทุบ mace Density V/Breach IV
  แล้ว Wind Burst เด้งตัวขึ้นทุบซ้ำเป็นสายพานสูงสุด 3 ครั้ง

ใยแมงมุม/ลาวา/น้ำที่บอทวางเป็นบล็อกชั่วคราว **คืนค่าเดิมเอง** (ตั้งเวลาใน config / ปิดทั้งหมดที่ `traps-enabled: false`)

## ความฉลาดของบอท
- เลือกเป้าแบบให้คะแนน: ใกล้ + เลือดน้อย + ไม่สลับเป้าไปมา, ป้องกันตัวจากคนที่เพิ่งตี, โดนตีตัวเดียวทั้งทัพหันมาช่วย
- ล้อมเป็นวงรอบเป้า (แต่ละตัวคนละมุม) ไม่เดินแถวเดียว, สลับทิศหลบเมื่อโดนตี
- ตั้งโล่ใส่ธนู/หน้าไม้/ตรีศูล, ไม่ตั้งโล่เมื่อเป้าเลือดใกล้หมด (รีบจบเกม)
- ติดกำแพง/หลุม → กระโดด → ปาเพิร์ล → วาร์ปไปหาเป้า
- ตัดใยแมงมุมที่ติดเอง, ขึ้นจากลาวา, เทน้ำดับไฟตัวเอง
- ตายแล้วดรอปของ (`drop-items: true` ใน config)

## Build
- GitHub: push แล้วดูไฟล์ใน Actions → Artifacts → `BotByMaroneya.jar`
- เครื่องตัวเอง: `mvn package` → `target/BotByMaroneya.jar`
- ถ้า build ไม่ผ่านเพราะหา Citizens ไม่เจอ ให้แก้เลขเวอร์ชัน `citizens-main` ใน `pom.xml`

ค่าปรับแต่งทั้งหมดอยู่ใน `config.yml`

## แจ้งเตือนเข้า/ออกเกม
ตอนเสกบอทจะขึ้น `ชื่อบอท joined the game` และตอน `/debot` จะขึ้น `left the game` ทยอยทีละตัว
ปิดได้ที่ `broadcast-join-leave: false` ใน `config.yml`
